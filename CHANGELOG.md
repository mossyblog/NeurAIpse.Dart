# Changelog

## 0.6.0

- Spacing Box: drag handles that snap to tokens and faint token guides; Type: font-size and line-height guide ladder with stepper snap.
- Layout mode (L): drop wireframe components on the page as `kind:"placement"` annotations, output under `### Layout placements`.
- Rearrange mode (R): move, resize, nudge or hide existing elements with snap guides; saved per route as `kind:"rearrange"` annotations and copied as a `### Rearrangements` section.

## 0.5.2

- Box mode selects whole rings (spec 14.2, approved mock): hovering a padding, margin or gap zone previews its whole group with a pill per side, a click selects it, side clicks narrow, Shift toggles, Esc steps back, 0 sides keep an 8px grab, arrows step tokens, the panel diagram, presets, chips and `This element | All N like this` scope edit every selected side, and Copy maps the selection to `padding` / `padding-block` / `padding-top` / `gap` with split, 0-side, shared-gap and viewport notes (the Shift-click sibling pin and the unshipped I9 toggles are removed).

## 0.5.1

- Inspector I3b (spec 14): the spacing inspector has two mutually exclusive sub-modes, Box and Lines, fixing the regression where the box overlay (tinted rings, a pill on every side, gap bands) and the line overlay (guides, measure, dashed support) rendered together. A `Box | Lines` segmented control sits in the toolbar while Spacing is on; `V` toggles it (only in Spacing; P L H C X S M T K unchanged). The choice persists as `inspectorSubMode` (`"box"` default, `"lines"`) in `feedback-toolbar-settings`. Switching remounts the inspector, clearing hover, selection, pins, guides and measure, never pending `styleChange` records or the preview `<style>`.
- Box: border box plus thin untinted region outlines; only the region under the cursor is tinted, with ONE value pill (I5 human token labels). Click selects the region (solid outline) and opens the panel; a second click re-selects, never measures. No guides, measure, dashed lines, crosshair or Alt quick measure.
- Lines: crosshair cursor (a `<style data-annotate-cursor>` removed on switch and exit), hovered element edges only, click-click pins, guides, measure line and pill, dashed support, Alt quick measure. The first Esc clears pins, the second leaves Spacing. The panel shows only while a two-region measure can be added (element-edge pins measure but are not committable). Edit from the pending list switches to Box.
- Layer ownership as code: `core/spacing-modes.ts` (`LAYER_OWNER`, `ownsLayer`, `layersFor`, `nextSubMode`, `SUB_MODE_BEHAVIOUR`). Every overlay node is gated by it and carries `data-annotate-layer` (`ring`, `region-pill`, `gap`, `outline`, `note`, `edge`, `guide`, `measure`, `measure-pill`, `dashed`); layers of the inactive sub-mode are not mounted.
- Removed unused Collapsible imports from the spacing panel.

## 0.5.0

- Inspector I5: token resolution by stylesheet scan (`core/tokens-dom.ts`). Walks `document.styleSheets` and adopted sheets (`@layer`, `@media`, `@supports`, `@container`, `@scope`, `@import`, nesting), reads each matching rule's authored declaration through CSS Typed OM, and picks the cascade winner (importance, inline style, `@layer` order reversed for `!important`, specificity per matching selector, source order) with pure, tested `specificity()` and `pickWinner()`. Handles Tailwind v4: `calc(var(--spacing) * N)` and the bare ×1 form `var(--spacing)` become `--spacing × N`; canvas labels show the utility (`p-4 · 16`, `pt-1 · 4`) or `spacing×N`, never the bare `--spacing` variable (a class counts as a utility only when it ends in its multiplier), logical shorthands (`px-*` / `py-*`), `var(--tw-leading, var(--text-sm--line-height))` fallbacks, `--tw-*` chains, and component variables (`--card-padding`). Each winner is checked against the computed value; a mismatch, a cross-origin sheet (SecurityError caught) or a container query reports `token unknown` instead of guessing. The secondary `:root` inversion lists every equal token as a `guess`. Drift flags (`off-grid: 14px`, `no token`, `token unknown (guess: …)`) appear in the panel and on the record. Results are cached per stylesheet version and computed in `requestIdleCallback`; hover reads the cache only.
- Inspector I6: Type inspector (toolbar button and T). Hovering and clicking picks elements with direct text; the group is every element with the same computed signature (family, size, line-height, weight, letter-spacing), or with the same tokens when "Same token only" is on (`N unknown` counted). Shift-click adds or removes members, outlines and an `N elements` badge mark the group, and the panel edits size, line-height, weight and tracking with runtime token pickers (`--text-*`, companions, `--leading-*`, `--font-weight-*`, `--tracking-*`), raw input and steppers. A `--text-*` size pick carries its companion line-height. All members share one `data-annotate-group` value in the single preview style.
- Inspector I7: `### Measurements` and `### Style changes` sections after the feedback list at all four tiers (Compact one line per change; Standard selector, source, from→to with `var(--token)` / `calc(var(--spacing) * N)` and utility, measure, elements up to 5 then `+N more`, notes; Detailed every selector; Forensic computed before/after and the winning rule's selector, sheet and layer). `styleChangeStyle: "todo"` renders `- [ ] Change …` lines. Annotation-only output is byte-identical to 0.4.0 (golden test). Edits are `kind: "style-change"` annotations (spec 7.4 `StyleChange`, extras in `styleDetail`) and saved pins are `kind: "measure"`; they persist per route, copy, send, clear (including Clear on copy), show a toolbar count, have no markers, and can be edited or removed from the panel (re-attached by selector after a reload). Metadata copy formats ignore them. C and S now work with style changes alone.
- Inspector I8: Colour inspector (toolbar button and K, since C is Copy). Click any element to read `color`, `background-color`, `border-color` (when drawn) and `fill`/`stroke` (SVG); pick a colour token read from `:root` at runtime (`--color-*` first, then scanned colour variables such as `--primary` with `@theme inline`) or type hex/rgb/oklch; the WCAG contrast ratio against the element's effective background (translucent layers composited) updates live. "Same colour" extends the edit to every element with the same resolved value. Colour normalisation covers rgb, hex, hsl, lab, lch, oklab, oklch and `color()`.
- Dev fixture route `/dev/annotate-token-fixtures` (404 outside development) with Tailwind utilities, cascade conflicts, off-grid and duplicate tokens, a type group and colour cases.

## 0.4.0

- Inspector I1: Spacing inspector mode (toolbar button and M; Annotate and Spacing are exclusive, Esc returns to Annotate). Hovering draws the border box, margin ring and padding ring (tinted separately, px labels, pluggable token resolver hook that returns undefined until I5) inside the shadow root with `pointer-events: none`. Pure geometry in `core/spacing.ts` (`SpacingRegion` records `{kind, side, rect, value, element}`), hit-test by `elementFromPoint` then smallest-area region (children's margins and the hovered element stay candidates; zero-area regions and zero-size boxes snap within 8px). Negative margins draw at zero thickness and keep the real value; transforms scale the drawing from rects (`scaled ×0.5`, `approximate` for rotation/skew); inline elements draw per line box; vertical margins flag `may collapse`. Redraw on scroll, resize and page mutations, throttled to one per animation frame.
- Inspector I2: flex gap bands (row, column, wrap, reverse, rtl, `order`) between in-flow children's margin boxes, with the measured space shown when justify/align distribution widens a band; grid gap bands from Chromium's resolved `gridTemplateColumns/Rows` tracks plus gaps, spanning the full track block (subgrid and unresolved tracks are reported unsupported; `space-*` distribution is flagged approximate). Dev fixture route `/dev/annotate-inspector-fixtures` (404 outside development).
- Inspector I3: click-click pins with full-viewport guides at the region edges, measure lines for the disjoint, offset (dashed extensions), inside, overlap and same-edge cases, Alt-hover quick measure, Esc clears.
- Inspector I4: right side panel (320px, collapsible, light/dark) with element, region, Current vs New per property, token dropdown generated at runtime from the `--spacing` custom properties on `:root` (on-grid multiples first) with px readouts, raw number + unit input, stepper (±8 snapping to the grid, ±1 with Shift), Reset and a pending-changes list. Live preview writes one `<style data-annotate-preview>` keyed by generated `data-annotate-group` attributes, never inline styles; it is reverted on Esc, Clear all, mode switch and Exit. Specificity choice (spec risk 7): the tag is inserted first in `<head>` and wraps `!important` declarations in `@layer annotate-preview`, so the preview layer is declared before every page layer and beats authored normal and `!important` rules, layered or not (inline `!important` styles still win). Pending edits are held as spec 7.4 `StyleChange` records (exported from core, with `Annotation.kind` `"style-change" | "measure"`) for the I7 serializer; they survive mode switches, and X clears them.
